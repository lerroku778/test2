# Бар Лжецов: вечер с Чеколейтором

3D-карточная игра на блеф в духе Liar's Bar. Четыре игрока за столом в беседке бара, стол королей, дам или тузов. Карты кладут рубашкой вверх и врут с каменным лицом. Кого поймали на лжи, тот пьёт Чеколейтор. В одном глотке из шести отрава.

- Мультиплеер до 4 игроков по коду комнаты, без регистрации. Свободные места занимают боты.
- Одиночная игра против ботов работает прямо в браузере, даже без сервера.
- Партию ведёт сервер: чужие карты и номер отравленного глотка клиенту не отправляются.
- Три визуальных стиля (переключаются в меню): **мульт** (целшейдинг и контуры), **R.E.P.O.** (пиксели и дизеринг), **чистый** (PBR).
- Кнопка «Закурить» (Chapman Red), синтезированный звук, гитара, сверчки.

## Правила

1. Колода из 20 карт: по 6 королей, дам и тузов и 2 джокера. Каждому раздают по 5.
2. В начале раунда объявляется стол: королей, дам или тузов.
3. В свой ход кладёшь от 1 до 3 карт рубашкой вверх, заявляя, что это карты стола. Джокер подходит к любому столу.
4. Следующий игрок либо ходит сам, либо жмёт «ЛЖЕЦ!». Карты вскрываются.
5. Соврал — пьёт тот, кто клал. Сказал правду — пьёт тот, кто вскрывал.
6. У каждого своя бутылка на 6 глотков, один из них отравлен. Отравился — выбываешь.
7. Если карты остались только у одного игрока, следующий обязан его вскрыть.
8. Последний живой забирает бар.

Управление: мышь — осмотреться, `1`–`5` — выбрать карту, `Enter` — выложить, `L` — «Лжец!», `S` — закурить.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install --omit=dev
node server.js            # http://localhost:8080
PORT=3000 node server.js  # другой порт
```

Сервер раздаёт сайт и держит комнаты по WebSocket на пути `/ws`. Внешние зависимости: пакет `ws` и шрифты Google Fonts. Three.js лежит в `vendor/`, CDN не нужен.

### На VPS через systemd

`/etc/systemd/system/liars-bar.service`:

```ini
[Unit]
Description=Liars Bar game server
After=network.target

[Service]
WorkingDirectory=/opt/liars-bar
ExecStart=/usr/bin/node server.js
Environment=PORT=8080
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now liars-bar
```

### nginx и HTTPS

WebSocket требует заголовков `Upgrade`:

```nginx
server {
    server_name bar.example.com;
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 3600s;
    }
}
```

Сертификат: `sudo certbot --nginx -d bar.example.com`. Под HTTPS клиент сам подключается по `wss://`.

### Docker

```bash
docker build -t liars-bar .
docker run -d -p 8080:8080 --restart unless-stopped liars-bar
```

## Как играть с друзьями

1. Открой сайт и нажми «Создать комнату».
2. Нажми «Скопировать ссылку» и отправь её друзьям. Ссылка вида `https://твой-сайт/?room=ABCD`, код можно ввести и вручную.
3. Каждый выбирает себе персонажа, кто-то жмёт «Начать партию».

## Структура

| Файл | Что внутри |
| --- | --- |
| `server.js` | HTTP-статика и WebSocket-комнаты |
| `js/engine.js` | Правила, боты, фильтр видимости для каждого игрока |
| `js/room.js` | Комната: люди, боты, таймеры. Общий код для сервера и соло |
| `js/world.js` | Беседка, двор, мурал, гирлянды, свет, бутылки |
| `js/characters.js` | Персонажи, лица, кисти с пальцами, IK рук, анимации |
| `js/fx.js` | Карты на столе, дым, рвота, лужи, окурки |
| `js/post.js` | Стилизующий проход: контуры, сжатие светов, режим R.E.P.O. |
| `js/textures.js` | Процедурные текстуры (дерево, плитка, карты, этикетки) |
| `js/audio.js` | Синтезированные звуки и музыка |
| `js/main.js` | Рендер, камера от первого лица, интерфейс, связка с сервером |

Настройки через переменные окружения: `PORT` (8080), `HOST` (0.0.0.0), `MAX_ROOMS` (200).
